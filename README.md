# 🔐 Smart Login System

A simple and responsive **Smart Login System** built using **HTML5, CSS3, JavaScript, Bootstrap, and LocalStorage**.

The project provides a basic authentication flow where users can create an account, log in using their registered credentials, and access a welcome page displaying their username.

## 📌 Project Overview

Smart Login System is a front-end authentication project designed to practice handling user registration, login validation, and browser storage using JavaScript.

User information is stored in the browser's **LocalStorage**, allowing the application to retrieve registered users and validate login credentials without using a backend or database.

---

## ✨ Features

- 📝 User Registration
- 🔐 User Login
- 🚪 Logout functionality
- 👤 Personalized welcome message
- 💾 User data stored using LocalStorage
- 📧 Email validation during registration
- ⚠️ Required input validation
- 🚫 Prevents registering with an existing email
- 📱 Responsive layout using Bootstrap
- 🎨 Dark-themed modern interface
- 💡 Success and error messages

---

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling and custom design
- **JavaScript (ES6)** – Application logic and validation
- **Bootstrap** – Responsive layout and UI components
- **Font Awesome** – Icons
- **LocalStorage** – Storing registered users and logged-in user information
